# zero-pii-redactor (日本語ドキュメント)

ログ、AIプロンプト、テレメトリ、エッジ環境向けの、ReDoSフリー・超高速 個人情報（PII）マスキング・トークナイザー・仮名化ライブラリ。外部ランタイム依存ゼロ（Zero Runtime Dependencies）で動作します。

---

## 主な特長

1. **ReDoS（正規表現DoS）フリー**:
   - RFC 境界制限を適用した線形 $O(N)$ 状態遷移により、悪意ある文字列に対してもミリ秒未満で安全に処理。
2. **Luhn アルゴリズムによるクレジットカード番号検証**:
   - モジュロ10チェックサムを検証し、ランダムな16桁の数値による誤検知を排除。
3. **深い JSON オブジェクトの再帰的サニタイズ**:
   - ネストしたオブジェクトや配列、機密キー（`password`, `apiKey`, `secret` 等）を自動的にスクラビング。
4. **柔軟なマスキング & 仮名化モード**:
   - `mask`（部分マスク）、`replace`（置換タグ）、`pseudonymize`（ソルト付き決定論的ハッシュ）。
5. **可逆な暗号化トークナイザー**:
   - AES-GCM による安全な一時トークン化（`tokenize` / `detokenize`）。
